## 시스템 모듈 구조

**한 줄 요약: 회사 PC에 평문으로 있는 한국투자증권 앱키·시크릿(RISK-001)을 어떻게 지킬지 — B안(암호화) vs C안(개인 PC 이전), 최종 선택은 군주 결정 대기.**

| 비교 | B안. 키 파일 암호화(회사 PC 유지) | C안. 개인 PC로 이전 |
|---|---|---|
| 핵심 효과 | 파일 유출돼도 열 수 없음 | 회사 도메인 환경에서 키 제거 |
| 회사 PC 노출 | 남음(암호화된 형태) | 없음(근본 해소) |
| 구현 | Windows DPAPI(사용자 계정 귀속 암호화, 추가 의존성 0)로 즉시 가능 | 개인 PC 상시 가동·루틴 이전 필요 |
| 운영 변화 | 없음(현행 유지) | 실행 거점 전체 이동(ARC-001·004에 연쇄) |
| 잔여 위험 | 회사 PC 계정 자체가 탈취되면 무력 | 개인 PC 보안 수준에 의존 |

**확정(군주 결정)**: 단기는 **B안** — Windows DPAPI로 키 파일을 암호화하고 토큰 캐시도 암호화 범위에 포함한다. 장기 **C안(개인 PC 이전)은 실전 예수금을 증액하기 전에 재검토**한다(아래 확정 섹션).

## 데이터 흐름 (Data Flow)

- B안 기준: 평문 키 파일 → DPAPI로 암호화 저장 → KIS 어댑터([[ARC-003]])가 기동 시 복호화해 메모리에만 보유 → 토큰 캐시 파일도 동일하게 암호화.
- 복호화된 키는 어댑터 모듈 밖으로 나가지 않는다.

## 인프라/의존성

- DPAPI는 Windows 내장(zero-dependency 유지). C안 선택 시 개인 PC의 Node 환경·상시 가동 체계가 선행 조건.

## 보안 및 인증

- 공통 불변식(어느 안이든): ① 키·토큰은 git·refs에 절대 커밋 금지(.gitignore 강제) ② 실전 예수금 50만원 유지로 피해 상한 제한 ③ 키 경로·내용을 로그·문서에 적지 않는다.

## 위험

- B안: 같은 Windows 계정으로 실행되는 악성 코드에는 DPAPI도 무력 — 계정 보안이 전제.
- C안 전환기: 두 PC에 키가 동시에 존재하는 기간 최소화, 이전 후 회사 PC 키 완전 삭제 확인 필요.
- 결정 지연 자체가 위험: 그동안 평문 상태 지속.

## 확정 (군주 결정 반영, 2026-11-24)

1. **단기 B안 확정**: Windows DPAPI로 키 파일 암호화(RISK-001 대응). **토큰 캐시 파일도 암호화 범위에 포함**한다.
2. **장기 C안(개인 PC 이전)은 실전 예수금 증액 전에 재검토** — 예수금 50만원을 올리려면 그 전에 C안 여부를 다시 결정한다.
