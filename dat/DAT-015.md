## 상위 근거

**REQ-029 — 책사 관직 가중: 종사 x1·참군 x2·군사중랑장 x3 승진·강등**

## 엔티티 스키마 (단일 테이블)

**한 줄 요약: 책사 7인+제갈량의 현재 관직·가중치·적중 통계를 들고 있는 현황 파일(장부 [[DAT-014]]에서 언제든 재계산 가능).**

- 엔티티: AdvisorRank (책사 1인 = 레코드 1건, 총 8건)
- 저장: `%USERPROFILE%\gujiga-data\council\ranks.json` — 운영 장부는 저장소(코드 레포) 밖에 둔다(레포 안 `trading/` 경로 아님).

## 필드 정의 및 타입

| 필드 | 타입 | 설명 |
|---|---|---|
| advisor | string | 책사 이름(곽가 등 8인) |
| rank | enum | `종사` \| `참군` \| `군사중랑장` |
| weight | int | 1 \| 2 \| 3 (rank에 1:1 대응) |
| total_judged | int | 누적 판정 건수(hit+miss, excluded 제외) |
| total_hits | int | 누적 적중 건수 |
| hit_rate | number | 누적 적중률(%) |
| recent10_hit_rate | number\|null | 최근 10건 적중률(10건 미만이면 null) |
| history | array | 승진·강등 이력 `[{at, from, to, reason}]` |
| updated_at | string(ISO) | 마지막 재계산 시각 |

## 인덱스 및 제약조건

- advisor당 1건. weight는 rank에서 파생(불일치 금지).
- 이 파일은 **파생 캐시**: 정본은 판정 장부([[DAT-014]])이며, 전체 재계산 시 동일한 값이 나와야 한다(멱등).
- 강등은 종사(x1) 아래로 내려가지 않는다.

## API 데이터 규격

- 조회: 공적판([[SCR-010]])·의견 기록 시 rank_at_time 스냅샷용.
- 쓰기: 채점 배치의 관직 재계산만.

## 마이그레이션 영향도

- 신규 파일. 최초 상태는 8인 전원 종사(x1). 장수 관직([[DAT-011]])과는 별개 파일·별개 개념.
