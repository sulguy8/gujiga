## 배경 및 맥락

**한 줄 요약: 매일 아침의 큰 판단 — 시장 날씨(방어/공격/중립)와 재진입 신호등(동남풍 N/6) — 을 정확한 숫자 규칙과 정해진 데이터 출처로 판정한다.**

촉군(트랙A)의 출병 조건이 신호등 단계에 걸려 있으므로, 이 판정이 세력전·실전 운용의 대문이다. 정의는 refs/ops/spec_morning.md 22~23행을 정본으로 한다.

## 아이디어 / 논의 내용

**시장 날씨** (spec_morning.md 22행 그대로):
- 야간선물 -2% 이하 **또는** (코스피 20일선 아래 + 외국인 순매도) = **방어**
- 야간선물 +1% 이상 **이고** 20일선 위 = **공격**
- 나머지 = **중립**

**재진입 신호등 6개** (23행 그대로, 켜짐/꺼짐 + 근거 수치):
1. 악재 둔화(악재 뉴스에도 보합 이상 마감)
2. VIX 종가 30 미만
3. SOX가 장부 기준 저점을 최근 3거래일 안 깨고 반등
4. 코스피 외국인 순매수 2일 연속
5. 큰 이벤트 통과 후 다음 날 코스피 -1.5% 이상 하락 없음(2거래일 내 큰 이벤트 남아 있으면 꺼짐)
6. 코스피 종가 > 20일선

**단계**: 1~5 중 0~1개 = 대기, 2~3개 = 1차, 4개 이상 = 2차, 6번 켜짐 = 3차, 1차 후 기준 저점 재이탈 = 중단. **촉군 출병 조건은 1차 이상.** 기준 저점 갱신 시 장부 '재진입 기록'을 고친다.

**데이터 출처**:
- KRX 공식 종가·20일선·60일 일봉: KIS 일봉(`FID_COND_MRKT_DIV_CODE=J`)
- 장중 지수: 네이버 m.stock 지수 API
- 밤사이 미국(S&P·나스닥·SOX·VIX)·야간선물: 군사 엔진([[NTE-006]])의 웹 검색 1회
- 코스피 외국인 순매수: KIS 투자자 동향 TR — **정확한 TR id는 미확정**(장수가 refs/api 확인 후 제안, 군사 검토)
- **금지**: 네이버 일봉·basic은 NXT(대체거래소) 거래 포함이라 종가 판정에 쓰지 않는다(retro 교훈, spec_morning.md 18행).

## 결정사항

날씨·신호등·단계의 숫자 정의는 spec_morning.md 22~23행을 그대로 채택하고, 종가 판정 데이터는 KIS 일봉(J)만 쓰며 네이버 일봉은 판정 금지한다. 이유: 이미 실운용에서 검증된 규칙이고, NXT 포함 데이터로 인한 오판정을 원천 차단하기 위함.
