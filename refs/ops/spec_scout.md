# 척후(斥候) = 장중 5분 정찰 명세 (평일 09:00~15:25)

목적: 장중 변화를 5분마다 짧게 확인하고, 군주가 움직여야 할 일이 있을 때만 알린다. 주문은 절대 넣지 않는다(실전·모의 모두). 비용 최소: WebSearch 금지, 페이지 읽기 금지, JSON 조회만, 보고는 짧게.

## 0. 건너뛰기
- 현재 시각(KST)이 09:00 전, 15:25 이후, 또는 15:03~15:08(전황 보고 루틴 시간)이면 아무 조회 없이 '[건너뜀] HH:MM' 한 줄로 끝.
- trading\STOP 파일이 있으면 '[정지] STOP 파일' 한 줄로 끝.

## 1. 대상 읽기 (파일)
- trading\portfolio.md '관심 종목'(정탐 중인 성): 코드, 진입 가격대(규칙 초안의 '숫자~숫자원')
- trading\군영.md '출병 중인 부대': 코드, 손절(KRX 종가), 목표, 그리고 '오늘 작전' 섹션이 있으면 그 조건
- trading\mock_portfolio.md '보유'와 '미체결 주문'
- 직전 정찰 스냅샷: trading\data\scout_last.json ({time, prices:{code:price}, kospi, kosdaq})

## 2. 조회 (REPL, 탭 하나 열고 끝나면 닫기)
- const kis = eval(await fs.readFile('<ASIDE_ROOT>\\trading\\kis_client.js','utf8')); const real = await kis.make('real'); const mock = await kis.make('mock');
- 현재가·시가·고가·저가·거래량: real.price(code) -> {price, chg, open, high, low, vol, volVsPrev(전일 대비 거래량 비율 %)} (대상 종목 전부, '오늘 작전'의 목표·예비 성 포함)
- 지수: https://m.stock.naver.com/api/index/KOSPI/basic, /KOSDAQ/basic (fluctuationsRatio)
- 모의 체결: mock.fills(오늘) 에서 오늘 체결 수량이 0보다 큰 매수·매도
- 실전 잔고는 '출병 중인 부대'가 있을 때만 real.balance()

## 3. 알림 조건 (하나라도 해당하면 [액션 필요])
1. 정탐 중인 성의 현재가가 진입 가격대 안으로 들어옴 (직전 스냅샷에선 밖이었을 때만, 같은 성 하루 1회)
2. 실전 출병 부대: 현재가가 손절선 +2% 이내 또는 아래, 목표가 도달, 또는 직전 대비 ±3% 급변
3. 모의: 직전 정찰 이후 새로 체결된 주문(위군 매복 체결 등)
4. 급변: 대상 성이 직전 스냅샷 대비 ±3% 이상, 또는 코스피·코스닥이 직전 대비 ±1.5%p 이상
5. 군영 '오늘 작전'에 시각 조건이 있으면(예: 15:10 정찰 조건) 그 시각 회차에 조건 충족 여부 판정
- 해당 없으면 '[이상 없음] HH:MM 코스피 x% 코스닥 y%' 한 줄로 끝(종목 나열 금지).

## 4. 보고 ([액션 필요]일 때만, 최대 5줄, 삼국지 표현 가볍게)
- 첫 줄: '[액션 필요] HH:MM' + 한 줄 요약
- 이어서 항목별 1줄: 성 이름 | 현재가(등락) | 무엇이 일어났나 | 군주가 할 일(예: '출사표 확인 후 실행 여부 결정', '15:20 전 회군 판단')
- 숫자는 정확하게. 주문 권유는 출사표·군령 범위 안에서만.

## 5. 쓰기
