# 차트 판단 템플릿 (사용자 제공 이미지를 바로잡아 정리)

자동 채점: trading\chart_check.js. 데이터는 한투 KIS 일봉(KRX 공식). 장 마감 후에 돌려야 정확(장중엔 오늘 봉·거래량 미완성).
위치: '언제 사나(패턴)' 도구. '왜 사나(통찰)'와 시장 날씨를 대신하지 않는다.

## 0. 필터 (점수보다 먼저)
- 추세선이 최근 5일간 -0.5% 넘게 하락 중이면 매수 금지. 추세선 = 60일선, 상장 60거래일 미만은 5일선
- 시장 날씨가 방어면 '사라'도 '관찰'로 낮춤

## 1. 추세
| 항목 | 점수 |
|---|---|
| 추세선 상승 방향 | +1 |
| 종가 > 20일선 (신규상장은 5일선) / 아래 | +1 / -1 |
| 최근 3일 내 골든크로스(5/20) / 데드크로스 (신규상장 제외) | +1 / -1 |

## 2. 캔들
| 항목 | 정의 | 점수 |
|---|---|---|
| 큰 양봉 / 큰 음봉 | 몸통 4% 이상, 몸통이 길이의 60% 이상 | +1 / -1 |
| 망치형 | 10일 저점 부근, 아래꼬리 >= 몸통 2배, 위꼬리 짧음 | +1 |
| 유성형 | 10일 고점 부근, 위꼬리 >= 몸통 2배 | -1 |
| 상승/하락 장악형 | 오늘 몸통이 어제 반대색 몸통을 감쌈 | +1 / -1 |
| 모닝스타 / 이브닝스타 | 큰 음봉(양봉) -> 작은 몸통 -> 첫 봉 중간을 넘는 반대 봉 | +2 / -2 |
| 상장 후 최저가 반등 (신규상장) | 오늘 저가가 상장 후 최저, 양봉, 고가 근처(길이 60% 이상 위) 마감 | +1 |
| 십자선 | 몸통이 길이의 10% 이하 | 0, 기다려 |
| 하라미 | 3% 이상 큰 봉 몸통 안의 작은 봉 | 0, 추세 힘 약화 |

## 3. 패턴 (20~40일)
| 항목 | 점수 |
|---|---|
| 20일 박스 상단 돌파 (거래량 2배 이상이면 진짜) | +2 (부족하면 +1) |
| 20일 박스 하단 이탈 | -2 (부족하면 -1) |
| 박스권(폭 12% 이하) | 0, 기다려 |
| 쌍바닥 완성(저점 차 3% 이내, 넥라인 돌파) / 쌍봉 완성 | +2 / -2 |
| 삼각수렴(고점 하락, 저점 상승) | 0, 기다려 |

## 4. 거래량
- 기준: 20일 평균, 신규상장은 최근 5일 평균(상장 초 과열 거래량 왜곡 방지)
- 2배 이상: 신호 신뢰 / 0.7배 미만: 신호 약함

## 5. 시장 대비 상대 강도 (오늘)
- 지수보다 +3%p 이상 강함 +1, -3%p 이상 약함 -1

## 6. 결론
| 조건 | 판단 |
|---|---|
| +3 이상, 필터 통과 | 사라 (진입 검토, 손절 = 최근 10일 저가 또는 패턴 저점) |
| +3 이상, 매수 금지 | 기다려 |
| -3 이하 | 팔아라 |
| 십자선, 박스권, 삼각수렴 | 기다려 |
| 그 외 | 관찰 |

## 원본 이미지에서 바로잡은 것
- 음봉은 시가가 위, 종가가 아래 (이미지 '음선 = 시가 저가'는 오류)
- 하라미는 2봉 패턴. 이미지 Day4 그림은 망치형이고 Day6 '하라미선'은 삼각형 돌파 설명으로 내용 불일치
- 상승쐐기형: 이미지끼리 '사라 100%'와 '팔아라'로 모순, 교과서적으로 하락 신호 쪽. 템플릿에서 제외
- '100%, 80%' 성공률은 근거 없음. 실제 적중률은 백테스트로 확인
- 이동평균선 설정(5/5/100/200, 75일) 뒤섞임. 여기서는 5/20/60으로 통일
