# 병법서 (주식 삼국지 운영 규칙)

숫자와 데이터는 그대로 정확하게, 표현만 삼국지로. 표현 때문에 판단이 바뀌면 안 된다.

## 1. 세계관
| 삼국지 | 주식 |
|---|---|
| 군주 | 사용자 (최종 결정, 모든 실전 출병은 군주 명령으로만) |
| 군사(책사) | Aside (정탐, 계책, 기록. 실전 주문은 군주 '실행' 명령 후에만) |
| 병사 | 예수금. 1만원 = 병사 1명 (소수점 버림) |
| 성(城) | 종목. 매수 = 출병(입성), 매도 = 회군 |
| 군량 | 현금 비중. 사용 날짜가 정해진 돈은 군량이 아니다(관도대전) |
| 천시 | 시장 날씨(공격/중립/방어) |
| 지리 | 업종·테마(지형) |
| 인화 | 수급(외국인·기관) |
| 동남풍 | 재진입 신호등 6개 |
| 세작 | 공시·뉴스 감시 |

## 2. 포로 규칙 (병사는 죽지 않는다)
- 회군할 때 손실이 나면 그 금액만큼 병사가 '포로'가 된다(1만원 = 1명, 반올림).
- 이후 회군에서 수익이 나면 먼저 포로를 구출한다. 포로가 0이 된 뒤의 수익만 '전공'이다.
- 칠종칠금: 포로는 언젠가 풀려날 수 있다. 포로가 있다고 무리하게 출병하지 않는다(이릉대전).
- 포로 기록은 군영.md '포로 수용소'에 전투별로 남긴다.

## 3. 장수 카드 (종목 능력치, 각 0~100)
| 능력치 | 의미 | 산정(대략) |
|---|---|---|
| 무력 | 모멘텀 | 50 + 차트 점수 x 8 + 5일 지수 대비 %p (0~100으로 자름) |
| 지력 | 실적·통찰 | 수주·이익 성장·증권사 상향 확인 수에 따라 책사 판정(근거 1줄 필수) |
| 통솔 | 유동성 | 20일 평균 거래대금: 10억 미만 20, 50억 40, 200억 60, 500억 80, 1000억 이상 95 |
| 정치 | 몸값 | PBR 0.5 이하 90, 1 이하 75, 2 이하 55, 4 이하 35, 그 이상 20 (적자면 -10) |
| 매력 | 민심 | 최근 3일 외국인+기관 순매수 일수: 0일 20, 1일 40, 2일 60, 3일 80, 둘 다 3일 95 |
- 장수 유형 예: 무력·지력 높음 = 관우형, 정치 높고 통솔 낮음 = 산성, 매력 바닥 = 반란 중인 성.

## 4. 군령 (절대 규칙)
1. 출사표 없이는 출병 금지: 진입 가격대, 손절(KRX 종가), 목표, 기한, 병력 수를 먼저 적는다.
2. 삼고초려: 통찰·차트·확률 세 번 확인한 성만 출병 후보.
3. 읍참마속: 손절선(KRX 종가)은 예외 없이 지킨다. 실행은 다음 날 오전(급락일은 10:30 전 첫 반등).
4. 이릉대전 금지: 손실 직후 만회하려는 추가 출병(복수 매매) 금지. 포로가 생긴 날은 신규 출병 금지.
5. 연환계 금지: 같이 움직이는 성(상관 0.7 이상)에 병력 몰빵 금지.
6. 관도대전: 사용 날짜가 정해진 돈으로 출병 금지. 군량(현금) 최소 30% 유지.
7. 동남풍: 천시가 방어면 촉군(원칙 부대)은 출병하지 않는다. 정찰대(고육계)만 허용.
8. 공성계: 병력이 전부 성 밖(현금)이어도 조급해하지 않는다.

## 5. 관직과 병력 상한 (규율로 승진, 돈으로 승진하지 않음)
| 관직 | 한 성 최대 병력 | 동시 점령 성 | 승진 조건(누적) |
|---|---|---|---|
| 현령 | 20명(20만원) | 2성 | 시작 |
| 태수 | 30명 | 3성 | 출사표 작성 출병 5회, 군령 위반 0회, 논공행상 4주 참석 |
| 자사 | 40명 | 4성 | 출병 15회, 군령 위반 0회(최근 8주), 손절 준수 100% |
| 대장군 | 50명 | 5성 | 출병 30회, 최근 3개월 포로 구출률 100% 또는 전공 플러스 |
| 승상 | 군주 재량 | 군주 재량 | 대장군 6개월 유지 |
- 군령 위반 1회 = 승진 카운트 초기화(읍참마속). guard.json의 1회 주문 한도는 현재 관직 병력에 맞춘다.

## 6. 계책 사전
| 고사 | 상황 | 행동 |
|---|---|---|
| 적벽 동남풍 | 하락장, 신호 대기 | 신호등 2~3개면 1차, 4개면 2차 출병 |
| 매복(위군) | 가격대가 정해진 성 | 지정가 미리 걸기(B-예약형) |
| 정찰(고육계) | 천시 불리, 확인하고 싶을 때 | 병력 10명 이하, 모의 우선 |
| 장판파 | 지지선 사수 | 지지선 이탈 종가 = 회군 |
| 화공 | 갭상승·과열 | 시초가 추격 금지(아침 고점 A1), 오후 눌림 대기 |
| 철수(퇴각) | 기한 도래, 근거 소멸 | 시간 손절 |
| 칠종칠금 | 포로 발생 후 | 다음 출병은 같은 군령으로 차분히, 구출은 시간 문제 |

## 7. 세력전 (모의투자)
| 세력 | 트랙 | 전법 |
|---|---|---|
| 촉(유비) | 트랙 A | 동남풍 불 때만 출병 |
| 위(조조) | B-예약형 | 08:15 매복 지정가 |
| 오(손권) | B-확인형 | 15:05 전황 확인 후 출병 |
- 월요일 논공행상에서 세 나라 순위(손익, 출병 수, 매복 성공률)를 매긴다.
