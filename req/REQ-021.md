## 상위 근거

**NTE-007 — 시장 날씨·재진입 신호등·시장 데이터**

이 논의에서 **내려진 결정**이 있으면 여기에 적으세요(없으면 비워 둬도 됩니다). 내용이 있으면 카드에서 'AI로 등록' 한 번으로 의사결정 페이지에 ADR로 승격됩니다 — 무엇을/왜 택했는지 한두 줄로.

> 위 상위 문서의 맥락을 반영해 아래 섹션을 작성하세요.

## 배경

**한 줄 요약: 재진입 신호등 6개(동남풍 N/6)를 켜짐/꺼짐으로 판정하고, 켜진 개수로 단계(대기→1차→2차→3차/중단)를 정한다 — 촉군 출병의 대문.**

정의 정본은 refs/ops/spec_morning.md 23행.

## 요구사항 (단일)

신호등 6개를 각각 켜짐/꺼짐 + 근거 수치로 판정하고, 1~5번 중 켜진 개수로 단계를 산출한다: 0~1개 = 대기, 2~3개 = 1차, 4개 이상 = 2차, 6번 켜짐 = 3차, 1차 진입 후 기준 저점 재이탈 = 중단.

## 사전조건

- 시장 스냅샷([[DAT-013]])에 필요한 값(VIX·SOX·외국인·코스피 종가·20일선·이벤트 캘린더·기준 저점)이 있다.
- 운영 상태 3종(`signal_inputs`·`reentry_record`·`event_calendar`)이 시드되어 있다(1회 시드 완료 2026-11-27 — Aside 장부 값, 읽기 전용. [[DAT-013]] '운영 상태 입력' 참조).

## 동작 규칙

- 신호등 6개(각각 근거 수치와 함께 기록):
  1. 악재 둔화 — 악재 뉴스에도 보합 이상 마감
  2. VIX 종가 < 30
  3. SOX가 장부 기준 저점을 최근 3거래일 안 깨고 반등
  4. 코스피 외국인 순매수 2일 연속
  5. 큰 이벤트 통과 후 다음 날 코스피 -1.5% 이상 하락 없음(2거래일 내 큰 이벤트 남아 있으면 꺼짐)
  6. 코스피 종가 > 20일선
- 1번(악재 둔화)·5번(이벤트)은 수치+캘린더로 판정하되 애매하면 군사 엔진 해석을 참고 표기(판정 자체는 보수적으로 꺼짐).
- **신호1 Aside 연동 — 그림자 기간 한시(2026-11-27 군주 상책)**: 군의 직전에 `shadow.syncSignal1FromAside`가 Aside `reports/<date>.json`의 `signals_on`에서 신호1(악재 둔화) 값을 **읽기 전용**으로 가져와 `signal_inputs`를 갱신한다. Aside 원본 쓰기 0건 · 당일 파일이 없으면 기존 값 유지 · 출처를 `signal1_source`에 기록. Aside 루틴 이관 후에는 수동/자동 판정으로 전환 예정.
- **촉군(트랙A) 출병 조건 = 1차 이상**([[NTE-003]] 연동). 기준 저점 갱신 시 장부 '재진입 기록' 수정.

## 상태와 예외 Handling

- 입력 결측 신호등은 꺼짐으로 판정 + 결측 표시(모르면 보수적).
- **신호2 VIX 휴장 유지(2026-11-27 군주 상책)**: 당일 밤사이 VIX가 null(미국 휴장 등)이면 직전 거래일 캐시의 VIX 값으로 판정한다(최대 3거래일, 초과 시 보수 꺼짐 유지). 이때 신호2 근거(basis)에 '미 휴장 — <날짜> 값 유지'를 명시하고, 스냅샷에는 `sources.vix='carried(<날짜>)'`로 남긴다([[DAT-013]]). **다른 지표(SOX 등)는 유지하지 않는다.**
- 중단 상태는 기준 저점 회복 판정 전까지 유지.

## 수용 기준 (AC)

1. VIX 29.9 → 2번 켜짐, 30.0 → 꺼짐.
2. 1~5 중 2개 켜짐 → 1차, 4개 → 2차, 6번 켜짐 → 3차, 1개 → 대기.
3. 1차 상태에서 기준 저점 재이탈 데이터 → 중단.
4. 단계가 1차 미만이면 촉군 매수 조건 검사가 불충족을 반환한다.
5. 각 신호등 판정에 근거 수치가 기록된다.
6. 당일 VIX null + 직전 거래일 VIX 28.4 → 신호2 켜짐, 근거에 '미 휴장 — <날짜> 값 유지' 포함. null이 4거래일째 이어지면 꺼짐.
7. Aside 당일 보고 파일이 없으면 신호1은 기존 `signal_inputs` 값 그대로이고, 있으면 `signal1_source`에 출처가 기록된다(Aside 원본 파일은 변경 0).

## 비기능 요구

- 판정은 순수 함수 + 일일 스냅샷 기록(재현 가능한 판정 이력). 신호1 Aside 동기화·VIX carry는 판정 함수 바깥(스냅샷 준비 단계)에서 입력을 만들어 넣는다 — 판정 함수 자체는 순수 유지.
