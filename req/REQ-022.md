## 상위 근거

**NTE-007 — 시장 날씨·재진입 신호등·시장 데이터**

이 논의에서 **내려진 결정**이 있으면 여기에 적으세요(없으면 비워 둬도 됩니다). 내용이 있으면 카드에서 'AI로 등록' 한 번으로 의사결정 페이지에 ADR로 승격됩니다 — 무엇을/왜 택했는지 한두 줄로.

> 위 상위 문서의 맥락을 반영해 아래 섹션을 작성하세요.

## 배경

**한 줄 요약: 어떤 숫자를 어디서 가져오는지 출처를 못 박는다 — 특히 네이버 일봉은 NXT 포함이라 종가 판정에 금지(retro 교훈).**

## 요구사항 (단일)

시장 데이터는 지정된 출처에서만 수집한다: KRX 공식 종가·20일선·60일 일봉 = KIS 일봉(`FID_COND_MRKT_DIV_CODE=J`), 장중 지수 = 네이버 m.stock 지수 API, 밤사이 미국(S&P·나스닥·SOX·VIX)·야간선물 = 군사 엔진 웹 검색 1회, 코스피 외국인 순매수 = KIS 투자자 동향 TR — 그리고 **네이버 일봉·basic은 종가 판정에 사용 금지**.

## 사전조건

- KIS 어댑터([[TSK-003]]) 동작, 군사 엔진([[NTE-006]]) 웹 검색 가능.

## 동작 규칙

- 종가·20일선 등 **판정에 쓰이는 값**은 KIS 일봉(J)만 — 다른 출처 값이 섞이면 판정 무효.
- 장중 지수(네이버 m.stock)는 참고·정찰용으로만, 종가 판정에는 미사용.
- 웹 검색은 군의당 1회로 묶는다(비용 — spec_morning.md 관습).
- **미확정**: 외국인 순매수의 정확한 KIS TR id — 장수(구현 Claude Code)가 refs/api 확인 후 제안하고 군사(Aside)가 검토, 군주 승인 후 본 REQ 개정.
- 각 수집값에 출처 태그를 함께 저장([[DAT-013]]의 source 필드).

## 상태와 예외 Handling

- 출처별 수집 실패 시: 해당 값 결측 처리(대체 출처로 몰래 채우지 않는다 — 판정은 결측 규칙대로 보수적으로).
- 네이버 일봉 경로가 판정 코드에 유입되면 기동 시 검사에서 차단.

## 수용 기준 (AC)

1. 판정에 쓰인 종가·20일선 값의 출처 태그가 100% KIS(J)다.
2. 코드 검사에서 네이버 일봉·basic을 판정 경로에 쓰는 참조가 0건이다.
3. 웹 검색 호출이 군의 1회를 넘지 않는다(호출 로그).
4. 수집 실패 항목이 대체 출처로 채워지지 않고 결측으로 표시된다.

## 비기능 요구

- KIS 호출은 1.2초 간격 준수(어댑터 경유).

## 제외 범위

- 판정 규칙 자체([[REQ-020]]·[[REQ-021]]), 외국인 순매수 TR id 확정(미결 — 장수 제안 후 개정).
