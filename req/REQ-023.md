## 상위 근거

**NTE-008 — 근거 고리: 가설→출사표→증거→승격**

이 논의에서 **내려진 결정**이 있으면 여기에 적으세요(없으면 비워 둬도 됩니다). 내용이 있으면 카드에서 'AI로 등록' 한 번으로 의사결정 페이지에 ADR로 승격됩니다 — 무엇을/왜 택했는지 한두 줄로.

> 위 상위 문서의 맥락을 반영해 아래 섹션을 작성하세요.

## 배경

**한 줄 요약: 근거 없는 출병은 없다 — 출사표는 가설 ID를 반드시 인용하고, 근거의 등급이 보낼 수 있는 병력을 정한다.**

## 요구사항 (단일)

매수 출사표는 가설 장부에 존재하는 근거 가설 ID 1~3개를 필수로 인용해야 하며(없으면 관문이 `no_rationale`로 차단), 인용 가설의 최고 등급에 따라 병력 상한이 제한된다: 검증됨 = 관직 한도 전부, 검증 중 = 관직 한도의 절반(버림), 가설 단계 = 정찰대 10명(10만원)까지.

## 사전조건

- 가설 장부([[DAT-008]])가 운용 중이고, 출사표에 `hypothesis_ids` 필드가 있다([[DAT-001]] 보강).

## 동작 규칙

- 근거 검사(관문 **② 출사표 성립 단계**에 포함): `hypothesis_ids`가 1~3개이고 전부 장부에 존재해야 성립. 위반 시 `block_reason='no_rationale'`.
- 등급 상한 검사(관문 **⑦ 관직 한도 단계**에서 함께): 인용 가설 중 **가장 높은 등급** 기준 —
  | 최고 등급 | 병력 상한 |
  |---|---|
  | 검증됨(verified) | 관직 한도 전부(현령 20명) |
  | 검증 중(testing) | 관직 한도 ÷ 2 버림(현령 10명) |
  | 가설(hypothesis) | 정찰대 10명(10만원) |
- **매도(회군)는 근거·등급 검사를 적용하지 않는다** — 성벽 퇴각은 무조건 보장.
- AI 출사표([[REQ-017]])도 동일하게 근거 ID 필수.

## 상태와 예외 Handling

- 존재하지 않는 가설 ID·4개 이상 인용: 차단 + 사유 표시.
- 인용 가설이 폐기(discarded) 상태면 근거로 인정하지 않는다(차단).

## 수용 기준 (AC)

1. 근거 ID 없는 매수 출사표는 `no_rationale`로 차단된다(전송 0건).
2. 현령(한도 20명)에서 검증됨 근거 → 20명 통과, 검증 중 근거 → 11명 차단·10명 통과, 가설 근거 → 11명 차단·10명 통과.
3. 검증 중+가설 2개 인용 시 검증 중 기준(절반)이 적용된다(최고 등급).
4. 매도 출사표는 근거 ID가 없어도 차단되지 않는다.
5. 폐기 가설만 인용한 출사표는 차단된다.

## 비기능 요구

- 등급 상한 수치는 설정으로 관리(관직 표와 함께).

## 제외 범위

- 증거 적립·판정([[REQ-024]]·[[REQ-025]]), 관직 한도 자체([[REQ-013]]).
