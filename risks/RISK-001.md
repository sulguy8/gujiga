# RISK-001 — 증권사 API 키 평문 보관

## 리스크
회사 PC에 실전 한국투자증권 앱키·시크릿이 평문 파일로 보관되어 있어 유출 시 계좌에서 무단 주문이 실행될 수 있다.

## 배경
실전 투자용 한국투자증권 API 키 파일이 회사 PC에 암호화 없이 평문으로 존재한다. 키·토큰은 .gitignore로 git과 refs에는 절대 넣지 않도록 막아두었으나, 로컬 파일 자체의 보호 장치는 아직 없다.

## 완화 계획
실전 예수금을 50만원 수준으로 작게 유지해 피해 한도를 제한 중(적용됨). 추가로 키 파일 암호화(B안) 또는 개인 PC로 이전(C안) 중 하나를 결정해 적용해야 하며 현재 미결 상태다.

## 발생 시 영향
키 유출 시 제3자가 실전 계좌에서 무단 주문·매매를 실행할 수 있다. 예수금 한도(50만원)만큼 금전 손실이 발생하고 계좌 신뢰성이 훼손된다.
