## 상위 근거

**DAT-005 — 관심 종목 Watchlist**

**REQ-005 — 08:31 아침 브리핑 생성**
**NTE-002 — 정시 루틴: 08:31 브리핑·5분 정찰·15:05 마감 점검**
**한 줄 요약: 매매 판단을 즉흥이 아니라 "정해진 시각에, 미리 정한 숫자 규칙으로"만 내리도록 하루 일과를 고정한다.** (전문: `octet context NTE-002`)
**한 줄 요약: 거래일 아침 08:31에 그날의 작전 상황판(브리핑)이 자동으로 만들어진다.**
모의 주문 접수가 08:30부터 시작되므로, 접수 시작 직후인 08:31에 브리핑을 만들어 사람이 그날 계획을 확정하게 한다.
매 거래일 08:31에 관심 종목 상태·전일 결과·오늘 적용할 숫자 규칙을 담은 아침 브리핑이 자동 생성·표시된다.

## 화면 목적 (단일 화면)

**한 줄 요약: 매 거래일 08:31, 군의(軍議)처럼 그날의 전황·규칙·계획을 한 장으로 보여주는 브리핑 화면.**

사람이 아침에 이것만 보고 그날 계획을 확정한다([[REQ-005]]). 월요일에는 논공행상 결과([[REQ-010]])가 한 섹션으로 포함된다.

## UI/UX 흐름 및 인터랙션

- 진입 경로: 08:31 푸시 알림 탭(모바일) 또는 홈 → '오늘의 군의'(PC). 당일 브리핑이 기본, 과거 날짜 넘겨보기 가능.
- 사용자 동작: 읽기 전용이 기본. 관심 종목 행을 탭하면 출사표 작성([[SCR-001]] 경로)으로 이동.

## 컴포넌트 구조

| 구역 | 내용 |
|---|---|
| 머리 | 날짜 · "장 시작까지 N분" |
| 전황 요약 | 전일 결과 1~2줄(손익, 포로 발생 여부) |
| 관심 종목 표 | 종목별 상태 한 줄씩(아래 바인딩) |
| 오늘의 군령 | 적용 규칙 숫자(한도·군량·손절 기준) |
| (월요일만) 논공행상 | 촉·위·오 순위 표 |

## 데이터 바인딩

| 표시 항목 | 원천 |
|---|---|
| 관심 종목·가격대·성벽·목표·기한 | DAT-005 `watchlist` (status=observing/ready) |
| 전일 종가와 성벽까지 거리(%) | 시세 + `watchlist.stop_price` |
| 당일 시작 총평가·현금 | DAT-004 `daily_account_snapshot` |

| (월) 나라별 손익·출병 수·매복 성공률 | DAT-007 `nation_ledger` + 주간 집계([[REQ-010]]) |

## 에러/빈 상태 연출

- 관심 종목 0건: "척후 보낼 성이 없습니다 — 관심 종목을 등록하세요" + 등록 버튼.
- 일부 데이터 조회 실패: 해당 칸만 "조회 실패" 표시, 브리핑 자체는 생성([[REQ-005]] AC4).
- 휴장일: 브리핑 미생성 — 전일 브리핑에 "오늘 휴장" 띠.

## 수용 기준 (AC)

1. 거래일 08:31(±1분)에 생성되어 알림이 온다.
2. 관심 종목 상태·전일 결과·오늘 규칙 3요소가 모두 표에 보인다.
3. 월요일(휴장 시 다음 영업일)에는 논공행상 섹션이 포함된다.
4. 모바일 한 화면에서 표가 깨지지 않는다(가로 스크롤 없이 핵심 열 우선).
