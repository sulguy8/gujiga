## 상위 근거

**DAT-011 — 관직·군령 위반 GeneralRank·Violation**

**REQ-013 — 관직·승진·군령 위반 초기화 관리**
**NTE-005 — 삼국지 게임 레이어: 병력·관직·성벽으로 규칙 준수 게임화**
**한 줄 요약: 매매 규칙을 삼국지 게임 용어(병사·관직·성벽·포로)로 입혀서, 규칙 지키기를 의무가 아니라 게임처럼 재미있게 만든다.**
규칙 기반 매매의 최대 적은 규칙 자체가 아니라 "규칙을 지키기 싫어지는 마음"이다. 이미 군주·출사표 같은 삼국지 세계관을 쓰고 있으므로, 이를 앱 전반의 게임 레이어로 확장해 규칙 준수 자체에 재미와 명예를 부여한다.
매매 개념을 삼국지 용어로 1:1 대응시킨다.
1. **병력 환산**: 1만원 = 병사 1명. 투자금이 곧 병력이라 "이 전투(종목)에 몇 명을 보낼까"로 자금 관리를 직관화한다.

## 화면 목적 (단일 화면)

**한 줄 요약: '주군의 군영' — 벼슬, 삼국 정립, 점령 중인 성, 오늘의 군막 회의, 전리품과 포로를 한눈에 보는 홈 화면.**

화면 이름을 "군영 현황판"에서 **"주군의 군영"**으로 바꾼다(지령 016). 표 대신 카드·게이지로, 한눈에 "어디가 위험하고 무엇을 할지"가 보이게 한다. 규칙 준수의 성적표(벼슬·위반·포로)를 매일 마주하게 해, 게임 레이어가 습관을 만든다([[REQ-013]]·[[REQ-014]]). 숫자는 장부 값 그대로, 표현만 삼국지.

## UI/UX 흐름 및 인터랙션

- 진입 경로: 앱 홈(기본 화면). PC는 대시보드 좌측 고정.
- 사용자 동작: 성(종목) 게이지 탭 → 포지션 상세. 머리(벼슬) 탭 → 승진 조건 진행률 상세. 위반 기록 탭 → 위반 이력 목록. 나라 카드 탭 → 삼국 정립 화면([[SCR-006]]). 군막 회의 구역 탭 → 군막 회의 화면([[SCR-009]]).

## 컴포넌트 구조 (지령 016 개편 — 6구역)

| 구역 | 내용 |
|---|---|
| 1. 머리 | 날짜 · 벼슬(현령 등) · 다음 벼슬까지 진행("태수까지 출병 n/5") |
| 2. 상태 칩 | 천하 정세(수성/진격) · 봉화 n/6 켜짐 · 코스피 지수·등락 · 관문 열림/닫힘 |
| 3. 삼국 정립 | 나라 카드 3장(촉 초록 · 위 파랑 · 오 빨강): 손익 큰 숫자 · 군량 막대 · 점령 성 n/2 · 한 줄 상태(다음 할 일) |
| 4. 점령 중인 성 | 종목별 게이지: 성벽(손절) ─ 입성(평단) ─ 깃발(목표) 눈금 위에 현재가 점 · 성벽까지 % · 깃발까지 % · 퇴각 기한 D-n |
| 5. 오늘의 군막 회의 | 안건별 책사 7인 의견 칩(출병 초록 · 반대 빨강 · 관망 회색) + 군주 결정 한 줄 |
| 6. 전리품과 포로 | 실전·모의 구분 전공(포로 N명 · 구출까지 N만원 · 누적 전공) · 천하 대세(KODEX 200) 대비 |

- 위반 띠(기존 유지): 최근 군령 위반이 있으면 머리 아래에 "승진 카운트 초기화됨" 띠.
- 병력 환산(기존 유지): 총 병력 = 총자산 1만원 = 병사 1명, 군량 = 현금 비중 %(삼국 정립 카드의 군량 막대).

## 에러/빈 상태 연출

- 출병 0건: "전군 주둔 중 — 군량 100%".
- 포로 발생일: 화면 상단에 "오늘은 복수 출병 금지" 빨간 띠([[REQ-015]]).
- 군량 30% 근접(35% 미만): 군량 게이지 주황색 경고.
- 데이터 조회 실패: 해당 카드만 "집계 실패" 표시.
- 계좌 스냅샷 없음: "척후가 아직 돌아오지 않았습니다(08:30 도착 예정)" (지령 016 용어).
- 시세 미연결: "봉화가 끊겼습니다" + 기준 시각 표시 (지령 016 용어).
- 판정 0건(군막 회의·전공 구역): "아직 전공 없음" (지령 016 용어).

## 수용 기준 (AC)

1. 머리·상태 칩·삼국 정립·점령 중인 성·오늘의 군막 회의·전리품과 포로 여섯 구역이 모바일(380px)에서 깨지지 않고 1~2스크롤 안에 모두 보인다.
2. 포로 수·전공이 captive_ledger 최신 행과 일치한다(1만원=1명, 반올림).
3. 위반 발생 시 승진 카운트가 0으로 표시되고 위반 띠가 노출된다.
4. 승진 조건 충족 시 머리(벼슬)에 "승진 가능" 표시가 뜬다(확정은 군주 수락).
5. 화면 문구가 `src/ui_terms.js` 사전 값으로 표시된다(사전만 바꾸면 일괄 교체).
6. 점령 성 게이지에 성벽·입성·깃발 눈금과 현재가 점이 표시되고, 성벽까지 %·깃발까지 %·퇴각 기한 D-n이 장부 값과 일치한다.

## 구현 반영 확인 (지령 015)

- **종목명 사전**: `config/symbols.json`(코드→이름 사전) 신설 — 성 표의 종목명은 장부의 name 우선, 없으면 사전, 둘 다 없으면 코드만. '씨어스테크놀로지(458870)' 형식.
- **그림자 시세 캐시(새 산출물)**: 그림자 데몬이 장중 틱마다 `%USERPROFILE%\gujiga-data\market_cache\quotes_latest.json`(종목별 현재가 + updated_at 기준 시각)을 저장한다. 이 화면은 캐시를 **읽기 전용**으로 읽어 평가금액·수익률·성벽까지(%)를 계산하고, 표 아래 "시세 기준 HH:MM(그림자 최근 조회 — 실시간 아님)"을 표시한다. 캐시 없음 → "시세 캐시 없음 — 그림자 기동 후 생성", 해당 종목 가격 없음 → 성벽까지 "없음(시세 미연결)". 화면이 키·관문을 직접 부르지 않는 원칙 유지(장 마감 후엔 마지막 조회 시각 기준 — 기준 시각 표시로 구분).
- **하단 링크 4종 추가**: 책사단 의견판([[SCR-009]]) · 책사단 공적판([[SCR-010]]) · 병법서([[SCR-007]]) · 논공행상([[SCR-006]]) — 기존 세력전 대시보드 링크 옆.

## 지령 016 개편 (현황판 게임 화면·용어)

위 6구역 구성은 지령 016(군주 승인 시안) 기준이다. 아래 공통 규칙·용어표를 따른다.

### 공통 규칙(지령 016)

- 화면 문구는 아래 용어표대로 바꾼다. **화면에 보이는 말만 바꾸고, 데이터 필드명·장부 구조는 그대로** 둔다.
- 화면 문구 사전은 `src/ui_terms.js` **한 파일**로 모아 관리한다(화면마다 하드코딩 금지 — 사전만 바꾸면 일괄 교체).
- 읽기 전용·보안 규칙·"참고용, 최종 결정은 군주" 문구는 그대로 유지한다.
- 나라 색: 촉 초록 · 위 파랑 · 오 빨강. 밝은 베이지 톤 유지, 그라데이션·그림자·이모지 최소/금지. 모바일 폭 380px에서도 깨지지 않게.
- 숫자는 장부 값 그대로(꾸미지 않음). 틀린 숫자를 예쁘게 그리지 않는다(지령 015 데이터 수리 선행).
- 시안: `_campaign/orders/016-시안.html` (숫자는 2026-11-26 실제 값 예시).
