## 상위 근거

**DAT-011 — 관직·군령 위반 GeneralRank·Violation**

**REQ-013 — 관직·승진·군령 위반 초기화 관리**
**NTE-005 — 삼국지 게임 레이어: 병력·관직·성벽으로 규칙 준수 게임화**
**한 줄 요약: 매매 규칙을 삼국지 게임 용어(병사·관직·성벽·포로)로 입혀서, 규칙 지키기를 의무가 아니라 게임처럼 재미있게 만든다.**
규칙 기반 매매의 최대 적은 규칙 자체가 아니라 "규칙을 지키기 싫어지는 마음"이다. 이미 군주·출사표 같은 삼국지 세계관을 쓰고 있으므로, 이를 앱 전반의 게임 레이어로 확장해 규칙 준수 자체에 재미와 명예를 부여한다.
매매 개념을 삼국지 용어로 1:1 대응시킨다.
1. **병력 환산**: 1만원 = 병사 1명. 투자금이 곧 병력이라 "이 전투(종목)에 몇 명을 보낼까"로 자금 관리를 직관화한다.

## 화면 목적 (단일 화면)

**한 줄 요약: 내 군대의 모든 것 — 관직, 병력, 출병 중인 성, 포로, 전공 — 을 한눈에 보는 홈 화면.**

규칙 준수의 성적표(관직·위반·포로)를 매일 마주하게 해, 게임 레이어가 습관을 만든다([[REQ-013]]·[[REQ-014]]). 숫자는 그대로, 표현만 삼국지.

## UI/UX 흐름 및 인터랙션

- 진입 경로: 앱 홈(기본 화면). PC는 대시보드 좌측 고정.
- 사용자 동작: 성(종목) 행 탭 → 포지션 상세. 관직 카드 탭 → 승진 조건 진행률 상세. 위반 기록 탭 → 위반 이력 목록.

## 컴포넌트 구조

| 구역 | 내용 |
|---|---|
| 관직 카드 | 현재 관직 · 승진 진행(출병 N/5 등) · 위반 0 여부 |
| 병력 요약 | 총 병력(총자산 1만원=1명) · 군량(현금 비중 %) |
| 출병 중인 성 표 | 성 1곳 = 1행: 종목 · 병사 수 · 성벽까지 거리 % |
| 포로·전공 | 포로 N명 · 구출까지 N만원 · 누적 전공 |
| 위반 띠 | 최근 군령 위반(있으면) + "승진 카운트 초기화됨" |

## 데이터 바인딩

| 표시 항목 | 원천 |
|---|---|
| 관직·한도·승진 카운트 | DAT-011 `general_rank` (rank, sortie_count, clean_weeks, review_weeks) |
| 위반 기록 | DAT-011 `violation` 최근 행 |
| 출병 중인 성·병사 수 | DAT-006 `position` (open, 병사 = qty×avg_price÷10,000) |
| 성벽까지 거리·평가·수익률 | 현재가(그림자 시세 캐시 `quotes_latest.json`, 읽기 전용) vs `position.stop_price` |
| 포로·전공 | DAT-012 `captive_ledger` 최신 행(captives_after, merit_total_after) |
| 군량 비중 | 현금 ÷ 총자산 (기준 30%는 DAT-003) |

## 에러/빈 상태 연출

- 출병 0건: "전군 주둔 중 — 군량 100%".
- 포로 발생일: 화면 상단에 "오늘은 복수 출병 금지" 빨간 띠([[REQ-015]]).
- 군량 30% 근접(35% 미만): 군량 게이지 주황색 경고.
- 데이터 조회 실패: 해당 카드만 "집계 실패" 표시.

## 수용 기준 (AC)

1. 관직·병력·성·포로·전공 다섯 구역이 모바일 1~2스크롤 안에 모두 보인다.
2. 포로 수·전공이 captive_ledger 최신 행과 일치한다(1만원=1명, 반올림).
3. 위반 발생 시 승진 카운트가 0으로 표시되고 위반 띠가 노출된다.
4. 승진 조건 충족 시 관직 카드에 "승진 가능" 표시가 뜬다(확정은 군주 수락).

## 구현 반영 확인 (지령 015)

- **종목명 사전**: `config/symbols.json`(코드→이름 사전) 신설 — 성 표의 종목명은 장부의 name 우선, 없으면 사전, 둘 다 없으면 코드만. '씨어스테크놀로지(458870)' 형식.
- **그림자 시세 캐시(새 산출물)**: 그림자 데몬이 장중 틱마다 `%USERPROFILE%\gujiga-data\market_cache\quotes_latest.json`(종목별 현재가 + updated_at 기준 시각)을 저장한다. 이 화면은 캐시를 **읽기 전용**으로 읽어 평가금액·수익률·성벽까지(%)를 계산하고, 표 아래 "시세 기준 HH:MM(그림자 최근 조회 — 실시간 아님)"을 표시한다. 캐시 없음 → "시세 캐시 없음 — 그림자 기동 후 생성", 해당 종목 가격 없음 → 성벽까지 "없음(시세 미연결)". 화면이 키·관문을 직접 부르지 않는 원칙 유지(장 마감 후엔 마지막 조회 시각 기준 — 기준 시각 표시로 구분).
- **하단 링크 4종 추가**: 책사단 의견판([[SCR-009]]) · 책사단 공적판([[SCR-010]]) · 병법서([[SCR-007]]) · 논공행상([[SCR-006]]) — 기존 세력전 대시보드 링크 옆.
