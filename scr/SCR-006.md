## 상위 근거

**DAT-007 — 세력 장부 NationLedger**

**REQ-009 — 전략별 장부 분리: 촉·위·오 가상 잔고·체결 기록**
**NTE-003 — 모의 세력전: 한 계좌에서 전략 3개 장부 분리 성과 비교**
**한 줄 요약: 하나의 모의계좌 안에서 전략 3개(촉·위·오)를 장부만 나눠 돌리고, 어느 전략이 더 잘 버는지 숫자로 비교한다.** (전문: `octet context NTE-003`)
**한 줄 요약: 한 모의계좌 안에서 촉·위·오 세 전략의 돈과 기록이 절대 섞이지 않게 장부를 나눈다.**
장부가 섞이면 전략 비교 자체가 무의미해진다. 분리의 정확성이 세력전 전체의 기반이다.
모의계좌 내 가상 운용금 200만원을 촉(100만원)·위(50만원)·오(50만원)의 세 장부로 분리해, 각 체결·잔고·수익률이 해당 나라 장부에만 기록되게 한다.

## 화면 목적 (단일 화면)

**한 줄 요약: '삼국 정립·이번 주 논공' — 촉·위·오 세 나라의 전황과 매주 월요일 논공(순위)을 보는 대시보드.**

화면 이름을 "세력전·논공행상 대시보드"에서 **"삼국 정립·이번 주 논공"**으로 바꾼다(지령 016 — 화면 문구만, 데이터 필드명·장부 구조는 유지).

같은 시장에서 세 전략이 겨룬 결과를 숫자로만 판정한다([[REQ-009]]·[[REQ-010]]).

## UI/UX 흐름 및 인터랙션

- 진입 경로: 홈 '삼국 정립' 나라 카드([[SCR-005]]) 탭 → 상세. 월요일 브리핑([[SCR-002]])의 논공 섹션에서 "자세히"로도 진입.
- 사용자 동작: 나라 카드 탭 → 그 나라의 체결 내역·보유 성 목록. 주차 선택(지난 논공행상 넘겨보기).

## 컴포넌트 구조

| 구역 | 내용 |
|---|---|
| 나라 3장 카드 | 촉(트랙A, 초록)·위(B-예약, 파랑)·오(B-확인, 빨강): 배정금 · 잔고 · 수익률 — 홈 삼국 정립 카드와 같은 나라 색 |
| 이번 주 논공 표 | 주간 순위(화면 표기 "이번 주 논공"): 손익 · 출병 수 · 매복 성공률 · **근거 준수율** |
| 성적표 4분면 | 전공(수익·준수) / 요행(수익·위반 ⚠) / 명예로운 패배(손실·준수) / 진짜 실패(손실·위반) — 거래 건수 집계([[REQ-026]]) |

| 제한 현황 | 나라별 보유 성 수(최대 2) · 종목당 한도(25만원) 사용률 |

## 데이터 바인딩

| 표시 항목 | 원천 |
|---|---|
| 배정금·가상 잔고·수익률 | DAT-007 `nation_ledger` (allocated, cash, position_value, return_rate) |
| 주간 손익·출병 수 | DAT-002 `order_log` 주간 집계(nation별) |
| 매복 성공률 | 체결 예약 ÷ 걸어둔 예약(위나라만, 촉·오는 "해당 없음") |
| 보유 성 수·한도 사용률 | DAT-006 `position` (nation별 open) |

## 에러/빈 상태 연출

- 지난주 거래 0건 나라: 순위표에 0 / 해당 없음으로 표시(빠뜨리지 않음 — [[REQ-010]] AC4).
- 정합성 경고: 나라별 잔고 합계가 맞지 않으면 상단에 "장부 어긋남" 띠([[REQ-009]] AC2).
- 세력전 시작 전(데이터 없음): "출병 전 — 월요일 군의에서 개전합니다".

## 수용 기준 (AC)

1. 세 나라의 배정금(100/50/50만원)·잔고·수익률이 카드에 표시된다.
2. 논공행상 표의 세 지표가 장부 수기 검산과 일치한다.
3. 매복 성공률은 예약을 쓰지 않는 나라에 "해당 없음"으로 표시된다.
4. 주차를 바꾸면 해당 주의 논공행상이 다시 그려진다.

## 지령 016 개편 (현황판 게임 화면·용어)

- 화면 이름: "세력전·논공행상" → **"삼국 정립·이번 주 논공"**. "주간 순위표" 표기도 "이번 주 논공"으로.
- 나라 카드 3장에 나라 색 적용: 촉 초록 · 위 파랑 · 오 빨강(홈 [[SCR-005]] 삼국 정립 카드와 동일).
- 비교 기준선 KODEX 200의 화면 표기는 "천하 대세"(계산·데이터는 그대로).
- 숫자 판정 원칙("숫자로만 판정")·정합성 경고("장부 어긋남" 띠)는 그대로 유지.

### 공통 규칙(지령 016)

- 화면 문구는 아래 용어표대로 바꾼다. **화면에 보이는 말만 바꾸고, 데이터 필드명·장부 구조는 그대로** 둔다.
- 화면 문구 사전은 `src/ui_terms.js` **한 파일**로 모아 관리한다(화면마다 하드코딩 금지 — 사전만 바꾸면 일괄 교체).
- 읽기 전용·보안 규칙·"참고용, 최종 결정은 군주" 문구는 그대로 유지한다.
- 나라 색: 촉 초록 · 위 파랑 · 오 빨강. 밝은 베이지 톤 유지, 그라데이션·그림자·이모지 최소/금지. 모바일 폭 380px에서도 깨지지 않게.
- 숫자는 장부 값 그대로(꾸미지 않음). 틀린 숫자를 예쁘게 그리지 않는다(지령 015 데이터 수리 선행).
- 시안: `_campaign/orders/016-시안.html` (숫자는 2026-11-26 실제 값 예시).
