## 상위 근거

**DAT-014 — 책사 판정 장부 CouncilVerdict** · [[REQ-032]](제갈량 종합·가후 항상 표시)

## 화면 목적 (단일 화면)

**한 줄 요약: '군막 회의' — 오늘 안건에 대해 책사 7인이 뭐라 했고 제갈량이 어떻게 종합했는지 한 눈에 보는 화면 — 보고 결정하는 건 군주.**

화면 이름을 "책사단 의견판"에서 **"군막 회의"**로 바꾼다(지령 016 — 화면 문구만, 데이터 필드명·장부 구조는 유지).

## UI/UX 흐름 및 인터랙션

1. 안건 선택(기본: 오늘 안건 목록, 과거 날짜 이동 가능).
2. 책사 의견 표: 책사 / 관직(가중) / 입장(출병·관망·반대·회군) / 확신(1~5) / 한 줄 근거 / 산출 방식(rule·ai·fallback).
3. 제갈량 종합 박스: 종합 입장 + 입장별 가중합 내역("출병 4표 vs 관망 3표") + 확신 가중평균. 결정 순간엔 상·중·하책 표 풀이.
4. **가후 고정 영역**: 종합과 무관하게 화면 하단에 항상 가후 의견 표시(소수 의견 보호).
5. 불일치율 배지: 이 안건의 불일치율 %.
6. 실행 버튼 없음 — 이 화면은 읽기 전용. 진행하려면 기존 출사표 흐름([[SCR-001]])으로.

## 컴포넌트 구조

- AgendaPicker(안건 선택) / VerdictTable(7행) / SynthesisBox(제갈량) / GahuPanel(고정) / DisagreementBadge

## 데이터 바인딩

- `%USERPROFILE%\gujiga-data\council\verdicts.jsonl`([[DAT-014]] — 레포 밖 운영 장부)에서 agenda_id로 필터(의견 7건 + synthesis 1건). 관직은 rank_at_time 사용(현재 관직 아님).
- 보조 행 조인: `amend`는 (agenda_id, advisor)로 의견 행에 붙여 원문 의견(raw_view)·원본 근거(rationale)를 우선 표시, `aside_synthesis`는 agenda_id로 붙여 시범 종합·군주 결정을 표시.

## 에러/빈 상태 연출

- 오늘 안건 없음: "오늘 올라온 안건이 없습니다".
- 폴백 의견은 회색 + "엔진 불가" 표시(가짜 확신으로 보이지 않게).
- 유효 의견 4건 미만: 종합 박스 대신 "책사단 의견 불충분" 안내.

## 구현 반영 확인 (지령 013)

- AgendaPicker(안건 선택)는 **`?date=` 링크 목록**으로 구현됨 — 날짜별 링크를 눌러 과거 안건으로 이동(별도 위젯 없이 명세의 "과거 날짜 이동"을 충족).

## 구현 반영 확인 (지령 015)

- **원본 의견·근거 보존 표시**: 의견 칸은 raw_view(원문, 예: 장송의 '정보 없음')가 있으면 입장(enum) 대신 원문을 회색으로 표시. 근거 칸도 원본 한 줄 근거(why)를 우선 — 이미 이관된 행은 amend 보조 행을 조인해 보강. 가후 고정 영역도 같은 규칙.
- **시범 종합·군주 결정 표시**: 엔진 종합(synthesis 의견)이 없고 aside_synthesis 보조 행이 있으면 "제갈량 종합(시범 기록): 표 집계(tally) → 선택(pick)"으로 표시하고, 군주 결정(decision_pick, 결정 시각)을 별도 줄로 보여준다.
- **'종합 없음' 문구 상황별 3분기**: ① 시범 기록 이관분 — "엔진 종합 없음 — 시범 기록 이관분(원본에 종합 미기재)" ② 유효 의견(폴백 제외) 4건 미만 — "종합 없음 — 의견 불충분" ③ 그 외 — "종합 미기록".
- **날짜 이동·안건 필터**: `?date=YYYY-MM-DD` 링크로 날짜 이동(기본은 최신 날짜 — 장부가 쌓여도 무한 나열 방지), agenda_id로 안건 필터. 조건에 맞는 기록이 없으면 "해당 안건 없음" 안내.
- **복합 안건(종목 없음) 제목**: 종목명 대신 agenda_label(없으면 '복합 안건')로 표시. 종목명은 사전(config/symbols.json)으로 '이름(코드)' 형식.

## 지령 016 개편 (현황판 게임 화면·용어)

- 화면 이름: "책사단 의견판" → **"군막 회의"**. 홈 '오늘의 군막 회의' 구역([[SCR-005]])에서 탭하여 진입.
- 의견 칩 색: **출병 초록 · 반대 빨강 · 관망 회색**(회군·모름도 회색 계열). 폴백 의견의 회색 + "엔진 불가" 표시는 유지.
- 읽기 전용 원칙·가후 고정 영역·"보고 결정하는 건 군주" 톤은 그대로 유지.

### 공통 규칙(지령 016)

- 화면 문구는 아래 용어표대로 바꾼다. **화면에 보이는 말만 바꾸고, 데이터 필드명·장부 구조는 그대로** 둔다.
- 화면 문구 사전은 `src/ui_terms.js` **한 파일**로 모아 관리한다(화면마다 하드코딩 금지 — 사전만 바꾸면 일괄 교체).
- 읽기 전용·보안 규칙·"참고용, 최종 결정은 군주" 문구는 그대로 유지한다.
- 나라 색: 촉 초록 · 위 파랑 · 오 빨강. 밝은 베이지 톤 유지, 그라데이션·그림자·이모지 최소/금지. 모바일 폭 380px에서도 깨지지 않게.
- 숫자는 장부 값 그대로(꾸미지 않음). 틀린 숫자를 예쁘게 그리지 않는다(지령 015 데이터 수리 선행).
- 시안: `_campaign/orders/016-시안.html` (숫자는 2026-11-26 실제 값 예시).
