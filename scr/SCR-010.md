## 상위 근거

**DAT-015 — 책사 관직 상태 AdvisorRank** · [[DAT-014]](판정 장부) · [[REQ-031]](한목소리 경고)

## 화면 목적 (단일 화면)

**한 줄 요약: '책사 공적부' — 책사별 적중률과 관직(누구 말이 잘 맞았나)을 보여주는 화면 — 승진·강등과 한목소리 경고도 여기서 본다.**

화면 이름을 "책사단 공적판"에서 **"책사 공적부"**로 바꾼다(지령 016 — 화면 문구만, 데이터 필드명·장부 구조는 유지).

## UI/UX 흐름 및 인터랙션

1. 책사 8인(제갈량 포함) 카드 또는 표: 이름 / 관직·가중치 / 누적 판정 건수 / 누적 적중률 / 최근 10건 적중률.
2. 판정 10건 미만 책사는 적중률 옆에 **'참고 수준(표본 부족)'** 배지([[REQ-012]] 원칙).
3. 책사 클릭 → 승진·강등 이력(`history`)과 최근 판정 목록(안건·입장·결과·상대 수익률).
4. 상단 경고 배너: 최근 10안건 평균 불일치율이 임계 미만이면 "책사단이 한목소리입니다(가짜 다양성 의심)" 표시.
5. 읽기 전용 — 관직 수동 조정 버튼 없음(자동 재계산만).

## 컴포넌트 구조

- RankBoard(8인 요약) / AdvisorDetail(이력·판정 목록) / MonotoneWarningBanner / SampleSizeBadge

## 데이터 바인딩

- 요약: `trading/council/ranks.json`. 상세·불일치율: `trading/council/verdicts.jsonl` 집계.

## 에러/빈 상태 연출

- 판정 0건: "아직 전공 없음(첫 채점은 의견 후 5거래일)" (지령 016 용어).
- ranks.json 결손: 장부에서 재계산해 표시(파생 캐시이므로 복구 가능 안내).

## 구현 반영 확인 (지령 013)

- 책사 상세의 "최근 판정 목록"은 **최근 판정 20건 목록**으로 구현됨(/council/merit 공적판에 포함).

## 지령 016 개편 (현황판 게임 화면·용어)

- 화면 이름: "책사단 공적판" → **"책사 공적부"**.
- 빈 상태 문구: 판정 0건 → "아직 전공 없음(첫 채점은 의견 후 5거래일)".
- 읽기 전용(관직 수동 조정 버튼 없음)·'참고 수준(표본 부족)' 배지·한목소리 경고는 그대로 유지.

### 공통 규칙(지령 016)

- 화면 문구는 아래 용어표대로 바꾼다. **화면에 보이는 말만 바꾸고, 데이터 필드명·장부 구조는 그대로** 둔다.
- 화면 문구 사전은 `src/ui_terms.js` **한 파일**로 모아 관리한다(화면마다 하드코딩 금지 — 사전만 바꾸면 일괄 교체).
- 읽기 전용·보안 규칙·"참고용, 최종 결정은 군주" 문구는 그대로 유지한다.
- 나라 색: 촉 초록 · 위 파랑 · 오 빨강. 밝은 베이지 톤 유지, 그라데이션·그림자·이모지 최소/금지. 모바일 폭 380px에서도 깨지지 않게.
- 숫자는 장부 값 그대로(꾸미지 않음). 틀린 숫자를 예쁘게 그리지 않는다(지령 015 데이터 수리 선행).
- 시안: `_campaign/orders/016-시안.html` (숫자는 2026-11-26 실제 값 예시).
