## 상세 구현 범위

산출물:
- `secret.encrypt()/decrypt()` 유틸 — DPAPI(사용자 계정 귀속) 기반, 외부 패키지 없이 PowerShell/Node 내장 호출
- 평문 키 파일 → 암호화 파일 1회 전환 스크립트(전환 후 평문 삭제 안내 포함)
- 토큰 캐시 저장·로드 경로를 암호화 유틸 경유로 변경
- `.gitignore`에 키·토큰 경로 재확인(이미 있으면 유지)

## 수용 조건 (AC)

1. 전환 후 디스크에 평문 키 파일이 존재하지 않는다(군주 확인).
2. 암호화 파일을 다른 Windows 계정에서 복호화 시도하면 실패한다.
3. 암호화 상태에서 KIS 모의 API 호출 1회가 정상 동작한다(토큰 발급·캐시 포함).
4. 키·토큰 경로가 git 추적에 포함되지 않는다(`git status` 확인).
