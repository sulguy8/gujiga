## 상세 구현 범위

산출물:
- 5분 척후: 장중(09:00~15:30)만 실행, 조건 충족 시만 보고 기록, 연속 충족 중복 억제, 연속 3회 실패 시 두절 경고([[REQ-006]])
- 15:05 점검: 거리 계산, ±3% "판정 필요"·±0.5% "동시호가 경고" 목록 생성([[REQ-007]])
- 종가 판정: KRX 종가 < 손절선 → stop_breached_date 기록 → 익일 오전 매도 출사표 자동 생성. 급락일(-3% 갭 시가) 분기: 저가 +2% 첫 반등 또는 10:30 실행 대상([[REQ-008]] 확정 숫자)
- 모든 산출은 장부 기록 + notify 훅 자리(알림 자체는 [[TSK-011]])

## 수용 조건 (AC)

1. REQ-007 수치 예 재현: 성벽 10,000원·현재가 10,250원→판정 필요, 10,040원→동시호가 경고 추가.
2. 장중 일시 이탈 후 종가 회복 종목은 판정되지 않고, 종가 이탈 종목은 판정+익일 매도 출사표가 생성된다.
3. 급락일 분기: 전일 종가 10,000원·시가 9,650원이 급락일로 분류되고, 저가 9,500원 기준 9,690원 회복이 첫 반등으로 기록된다.
4. 생성된 매도 출사표도 실전이면 사용자 확인 없이는 전송되지 않는다(게이트 경유).
