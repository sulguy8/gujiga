## 상위 근거

**SCR-005 — 군영 현황판**

**DAT-011 — 관직·군령 위반 GeneralRank·Violation**
**REQ-013 — 관직·승진·군령 위반 초기화 관리**
**NTE-005 — 삼국지 게임 레이어: 병력·관직·성벽으로 규칙 준수 게임화**
**한 줄 요약: 매매 규칙을 삼국지 게임 용어(병사·관직·성벽·포로)로 입혀서, 규칙 지키기를 의무가 아니라 게임처럼 재미있게 만든다.**
규칙 기반 매매의 최대 적은 규칙 자체가 아니라 "규칙을 지키기 싫어지는 마음"이다. 이미 군주·출사표 같은 삼국지 세계관을 쓰고 있으므로, 이를 앱 전반의 게임 레이어로 확장해 규칙 준수 자체에 재미와 명예를 부여한다.
매매 개념을 삼국지 용어로 1:1 대응시킨다.

## 작업 목적

**목표: 로컬 웹 서버(localhost 전용) 뼈대와 첫 화면인 군영 현황판(SCR-005)을 구현한다 — 화면 중 최우선.** [4단계 화면 · 규모 L · 담당: Claude Code 구현 / 군주 확인(화면 검수)]

## 상세 구현 범위

산출물:
- 로컬 HTTP 서버(Node 내장 http, localhost 바인딩 — [[ARC-001]] 확정) + 정적 UI 서빙
- 군영 현황판: 관직 카드·병력 요약(1만원=1명)·출병 중인 성 표·포로/전공·위반 띠([[SCR-005]] 구성)
- 포로 발생일 "복수 출병 금지" 띠, 군량 35% 미만 주황 경고
- 장부 읽기 전용(이 화면에서 쓰기 없음)

## 수용 조건 (AC)

1. localhost 외 주소로 접근이 불가능하다(외부 바인딩 없음).
2. 관직·병력·성·포로·전공 다섯 구역이 표시되고, 값이 각 장부(general_rank·position·captive_ledger)와 일치한다.
3. 포로 발생일에 복수 출병 금지 띠가 뜬다.
4. SCR-005 AC 4건이 모두 통과한다(승진 가능 표시 포함).
