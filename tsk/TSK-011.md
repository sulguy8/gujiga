## 상세 구현 범위

산출물:
- notify 모듈: 브리핑·척후·점검·차단 알림이 모두 이 한 곳을 거침, 채널별 on/off 설정
- PC: Windows OS 알림(클릭 시 해당 화면 딥링크)
- 모바일: 텔레그램 봇 전송 — **본문은 종목·조건·수치만, 계좌번호·잔고 금액 제외**(ARC-006 확정 수위)
- 봇 토큰은 TSK-002 암호화 보관 규칙 적용, 알림 원문은 로컬 장부에 기록

## 수용 조건 (AC)

1. 척후 조건 충족 1건이 PC OS 알림과 텔레그램 양쪽에 도달한다.
2. 텔레그램 본문에 계좌번호·잔고 금액이 포함된 전송이 0건이다(본문 생성 코드에 필터 존재).
3. 텔레그램 장애 시에도 PC OS 알림은 정상 발송된다(채널 독립).
4. 봇 토큰이 git 추적·로그에 나타나지 않는다.
