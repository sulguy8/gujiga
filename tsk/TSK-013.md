## 작업 목적

**목표: strategist 코어 — `claude -p` 호출기, 권한 모델(읽기+초안만), 호출 상한, degrade — 를 구현한다.** [군사 엔진 1/2 · 규모 M · 담당: Claude Code 구현 / 군주 확인]

## 상세 구현 범위

산출물:
- `strategist.call(기능, 입력)` — child_process로 `claude -p` 호출(OCTET chat.js 방식), 구조화 출력(JSON) 파서·형식 검증
- 권한 모델: 도구 = 장부 읽기 + order_draft INSERT(created_by='ai'·user_confirmed=false 고정)만. 주문·플래그 함수는 도구 목록에 부재
- 호출 상한: 군의 1회·전황 1회·[액션 필요] 회차만 + 하루 최대 횟수(설정값, 초과 시 생략·기록)
- degrade: CLI 부재·실패·파싱 실패 시 규칙 엔진 값만으로 최소 보고
- 인젝션 방지: 외부 텍스트를 데이터 블록으로 감싸는 입력 빌더

## 수용 조건 (AC)

1. claude 미설치 환경에서도 파이프라인이 멈추지 않고 최소 보고가 나온다.
2. 하루 상한 도달 후 호출이 0건 추가되고 생략 기록이 남는다.
3. strategist가 접근 가능한 도구 목록에 주문·플래그 함수가 없다(코드 리뷰 + [[TST-012]]).
4. 파싱 실패 시 해당 기능만 생략되고 재호출이 발생하지 않는다.
