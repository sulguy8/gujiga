## 작업 목적

**목표: 출처별 수집기 4개(KIS 일봉 J·네이버 장중 지수·웹 검색·KIS 투자자 동향)를 구현하고, 출처 태그와 결측 처리를 포함한 수집 계층을 만든다.** [시장 데이터 1/2 · 규모 M · 담당: Claude Code 구현 / 외국인 TR은 장수 제안→군사 검토]

## 상세 구현 범위

산출물:
- daily-kis: KIS 일봉(`FID_COND_MRKT_DIV_CODE=J`)으로 종가·20일선·60일 일봉([[TSK-003]] 어댑터 경유)
- intraday-naver: 네이버 m.stock 지수 API(참고용 표기 고정)
- overnight-web: strategist 경유 웹 검색 1회 → 미국 4지표·야간선물 파싱
- investor-kis: 외국인 순매수 — **refs/api 확인 후 TR id 제안서 작성**(구현은 제안 승인 후)
- 공통: 출처 태그·결측 처리(대체 출처 금지), 네이버 일봉 참조 금지 코드 검사

## 수용 조건 (AC)

1. 거래일 아침 수집 1회로 [[DAT-013]] 필수 필드가 채워진다(외국인 제외 가능 — TR 미확정 시 결측 처리).
2. 모든 값에 출처 태그가 붙고, 종가·20일선 태그는 `kis_j` 100%.
3. 판정 경로 코드에 네이버 일봉·basic 참조 0건(자동 검사 통과).
4. 수집기 1개 실패 시 해당 값만 결측, 나머지 수집은 정상.
5. 외국인 순매수 TR id 제안서(근거 포함)가 작성되어 군사 검토로 넘어간다.
