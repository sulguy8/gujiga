## 작업 목적

**목표: 날씨(방어/공격/중립)와 신호등 6개·단계(대기/1차/2차/3차/중단) 판정을 순수 함수로 구현하고 시장 스냅샷에 기록한다.** [시장 데이터 2/2 · 규모 M · 담당: Claude Code 구현 / 군주 확인(판정 검산)]

## 상세 구현 범위

산출물:
- `judgeWeather(snapshot)` — [[REQ-020]] 규칙(야간선물 -2%/+1%, 20일선, 외국인), 결측 시 방어
- `judgeSignals(snapshot)` — 신호등 6개 켜짐/꺼짐+근거 수치, 결측 시 꺼짐([[REQ-021]])
- `judgeStage(signals, history)` — 0~1 대기 / 2~3 1차 / 4+ 2차 / 6번 3차 / 재이탈 중단, 기준 저점 갱신 시 재진입 기록 수정
- 촉군 출병 조건 함수: `stage ≥ 1차` ([[NTE-003]] 연동, 게이트·세력전에서 사용)
- market_snapshot 기록(판정 결과·근거·결측 포함, [[DAT-013]])

## 수용 조건 (AC)

1. [[REQ-020]] AC 4건(야간선물 -2.0%/-1.9%, +1.0% 분기, 결측→방어)이 그대로 통과한다.
2. [[REQ-021]] AC 5건(VIX 29.9/30.0, 단계 산출, 재이탈 중단, 촉군 조건, 근거 기록)이 그대로 통과한다.
3. 같은 입력에 항상 같은 출력(순수 함수 — 외부 호출 0).
4. 판정 결과가 스냅샷에 근거 수치와 함께 기록되어 재현 가능하다.
