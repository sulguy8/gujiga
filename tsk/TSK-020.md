## 상위 근거

**ARC-003 — 증권사 연동: KIS 어댑터와 단일 주문 게이트**

**SCR-001 — 출사표 확인·실행 모달**
**DAT-001 — 출사표 OrderDraft**
**REQ-001 — 출사표 필수 5항목 검증**
**NTE-001 — 실전 주문 안전장치: AI는 출사표(주문 초안)만, 실행은 사람이**
**한 줄 요약: AI는 주문 제안서(출사표)까지만 만들고, 실제 돈이 나가는 주문은 사람이 '실행' 버튼을 눌러야만 나간다.** (전문: `octet context NTE-001`)
**한 줄 요약: 출사표(주문 초안)는 5가지 항목이 모두 채워져야만 성립한다.**

## 작업 목적

**목표: 주문 게이트에 근거 검사(no_rationale)와 등급별 병력 상한 검사를 추가한다 — 근거 없는 출병을 관문에서 끝낸다.** [근거 고리 2/3 · 규모 M · 담당: Claude Code 구현 / 군주 확인]

## 상세 구현 범위

산출물:
- 게이트 **② 출사표 성립 단계** 확장: 매수 출사표의 `hypothesis_ids` 1~3개 존재·장부 실재·폐기 아님 검사 — 위반 시 `block_reason='no_rationale'`([[REQ-023]])
- 게이트 **⑦ 관직 한도 단계** 확장: 인용 가설 최고 등급 기준 병력 상한(검증됨=전부 / 검증 중=절반 버림 / 가설=10명) 검사
- **매도(회군) 예외**: 근거·등급 검사를 매도에 적용하지 않는 분기(성벽 퇴각 보장)
- block_reason enum에 `no_rationale`·`grade_cap` 추가([[DAT-002]] 반영은 구현 시 함께)
- AI 출사표 경로([[TSK-014]])의 근거 인용 필수 연동 확인

## 수용 조건 (AC)

1. [[REQ-023]] AC 5건이 그대로 통과한다(no_rationale 차단, 등급별 상한 경계 11/10명, 최고 등급 적용, 매도 무검사, 폐기 가설 차단).
2. 기존 게이트 검사 7단계([[TST-005]])가 회귀 없이 전부 통과한다.
3. 차단 로그에 새 사유(no_rationale·grade_cap)가 수치와 함께 남는다.
