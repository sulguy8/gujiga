## 상위 근거

**SCR-007 — 병법서(가설 장부) 목록·상세**

**DAT-008 — 가설 Hypothesis**
**REQ-011 — 가설 생애주기·증거 기록 관리**
**NTE-004 — 패턴 가설 검증 장부: 가설→검증 중→검증됨/폐기**
**한 줄 요약: 매매 아이디어를 가설 → 검증 중 → 검증됨/폐기 단계로 관리하며 증거를 날짜별로 쌓는다.** (전문: `octet context NTE-004`)
**한 줄 요약: 매매 가설을 분류(A~E)·상태(가설→검증 중→검증됨/폐기)·증거(날짜+한 줄)로 관리하는 장부를 만든다.**
몇 번의 우연을 법칙으로 착각하지 않도록, 가설은 증거가 쌓여야만 믿는 구조를 시스템으로 강제한다.

## 작업 목적

**목표: 병법서(SCR-007)와 논공행상(SCR-006) 화면에 근거 고리를 보이게 한다 — 진행 막대(N/10·출병 n/3), 판정 대기 군주 확정, 4분면 성적표.** [근거 고리 3/3 · 규모 M · 담당: Claude Code 구현 / 군주 화면 검수]

## 상세 구현 범위

산출물:
- 병법서 상세([[SCR-007]] 보강): 표본 진행 막대(N/10) + 출병 증거 n/3 표시, 판정식 표시, 등급별 병력 상한 안내
- 논공행상([[SCR-006]] 보강): 근거 준수율 열, 성적표 4분면 표(전공/요행⚠/명예로운 패배/진짜 실패 — [[REQ-026]]), '군주 판정 대기' 증거 목록 + success/fail 확정 버튼(judged_by='군주' 기록 — [[REQ-024]])
- 4분면 집계 로직(준수 판정: 근거 인용+성벽·기한 이행+위반 없음)

## 수용 조건 (AC)

1. [[REQ-026]] AC 4건이 그대로 통과한다(4분면 분류·별도 열·준수율 검산·요행 경고).
2. 병법서 상세에서 증거 7/10·출병 1/3 가설의 진행 막대가 정확히 표시된다.
3. 판정 대기 증거를 군주가 확정하면 judged_by='군주'로 기록되고 가설 집계가 갱신된다.
4. 명예로운 패배(손실·준수)가 진짜 실패와 시각적으로 구분된다(군주 의도 — 근거 준수의 명예 표현).
