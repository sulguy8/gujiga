## 상위 근거

**REQ-027 — 비교 기준선: KODEX 200 지수 보유 대비 성과**

**NTE-008 — 근거 고리: 가설→출사표→증거→승격**
**한 줄 요약: 모든 출병은 가설을 근거로 들고 나가고, 그 결과(출병이든 관찰이든)가 증거로 자동 적립되어 가설을 키우며, 커진 가설이 더 큰 병력을 허락한다 — 근거의 순환 고리.**
군주 의도: **주식을 재미있게 하되 근거대로 이행하는 것이 목적이다. 잃더라도 근거대로 했으면 그것이 중요하다.** 손익은 운이 섞이지만 근거 준수는 온전히 실력이므로, 시스템은 준수를 측정하고 보상한다.
**고리의 흐름**: 가설 장부([[NTE-004]]) → 출사표가 근거로 인용 → 출병 → 회군/기한 → 증거 자동 적립(+ 출병 안 한 날의 관찰도 적립) → 가설 승격 → 더 큰 병력.
**확정 결정 3가지(군주)**:
- **Q1. 근거 등급별 병력 상한**: 검증됨 = 관직 한도 전부 / 검증 중 = 관직 한도의 절반(버림) / 가설 단계 = 정찰대 **10명(10만원)까지**. 근거 가설이 여러 개면 **가장 높은 등급** 기준.

## 작업 목적

**목표: KODEX 200 기준선의 원장(일 1행)·계산 함수(순수)·화면 표시를 구현한다 — "지수보다 나은가"를 매주 자동으로 보여주는 거울.** [비교 기준선 · 규모 M · 담당: Claude Code 구현 / 군주 검산 확인]

## 상세 구현 범위

산출물:
- **기준선 원장**(일 1행, append 규율은 [[ARC-002]]): 날짜, KODEX 200 종가(출처 태그 `krx_official`), 실전 기준선 평가액(시작 2026-11-24 종가·50만원, 현금흐름 반영분), 나라별(촉·위·오) 기준선 평가액(시작 2026-11-23 종가·배정액), 결측 여부
- **계산 함수(순수)**: 수익률(우리/기준선), 초과수익(%p), 기간 최대 낙폭(우리/기준선), 주간 초과수익 연속 마이너스 주수
- **현금흐름 처리**: 입금·출금일에 그날 종가로 같은 금액 매수/매도 가정 반영
- **화면 반영**: 논공행상([[SCR-006]] — 주간 표에 기준선·초과수익 열)과 군영 현황판([[SCR-005]] — 요약 1줄), 4주 연속 마이너스 시 "지수 보유보다 못함" 경고 표시
- 수수료·세금 규칙 설정(기본: 둘 다 제외 — 양쪽 동일 규칙 강제)

## 수용 조건 (AC)

1. [[REQ-027]] AC 5건이 그대로 통과한다.
2. 원장이 거래일마다 1행씩 쌓이고, 같은 입력으로 재계산하면 같은 값이 나온다(순수 함수).
3. 논공행상·군영 현황판 양쪽에 4종 지표(우리/기준선/초과/낙폭)가 표시된다.
4. 결측일은 직전 종가 유지로 계산되고 화면에 결측 표시가 남는다.
