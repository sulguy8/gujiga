## 상위 근거

**SCR-006 — 세력전·논공행상 대시보드**

**DAT-007 — 세력 장부 NationLedger**
**REQ-009 — 전략별 장부 분리: 촉·위·오 가상 잔고·체결 기록**
**NTE-003 — 모의 세력전: 한 계좌에서 전략 3개 장부 분리 성과 비교**
**한 줄 요약: 하나의 모의계좌 안에서 전략 3개(촉·위·오)를 장부만 나눠 돌리고, 어느 전략이 더 잘 버는지 숫자로 비교한다.** (전문: `octet context NTE-003`)
**한 줄 요약: 한 모의계좌 안에서 촉·위·오 세 전략의 돈과 기록이 절대 섞이지 않게 장부를 나눈다.**
장부가 섞이면 전략 비교 자체가 무의미해진다. 분리의 정확성이 세력전 전체의 기반이다.

## 작업 목적

**목표: 세력 장부(nation_ledger) 계산과 세력전·논공행상 대시보드를 구현한다 — 촉·위·오 세 나라의 돈이 한 푼도 섞이지 않는 장부와, 매주 성적을 보는 화면.** [세력전 · 규모 L · 담당: Claude Code 구현 / 이관 검수·화면 검수는 군주]

## 상세 구현 범위

산출물:
- **nation_ledger 계산**([[DAT-007]]): 배정 촉(chok) 100만·위(wi) 50만·오(o) 50만(합 200만 강제) — 모의 체결(order_log의 nation)과 포지션([[DAT-006]])으로 나라별 현금·평가액·수익률 재계산
- **일일 정합성 검사**: 나라별 `cash + position_value` 합계가 배정+누적 손익과 불일치하면 경고([[REQ-009]] AC2)
- **Aside 모의 장부 이관(1회)**: `trading/mock_portfolio.md`의 보유·매매 기록을 읽어 장부 초기값 구성 — **읽기만, 원본 수정 금지**. 이관 리포트(원본 대사)
- **세력전 대시보드**([[SCR-006]] 보강 반영): 나라별 카드(배정·잔고·수익률·**기준선 대비 초과**([[TSK-022]])·보유 성), 월요일 순위(손익·출병 수·매복 성공률 — 예약형 아닌 촉·오는 '해당 없음')
- **보안 규칙**: 현황판·관문과 동일 — 화면은 읽기 전용, 127.0.0.1 전용([[ARC-001]]·[[ARC-009]])

## 수용 조건 (AC)

1. 모의 체결이 전부 정확히 한 나라에 귀속된다(무소속·중복 0 — [[REQ-009]] AC1).
2. 촉+위+오 장부 합계 정합성 검사가 통과하고, 일부러 어긋낸 데이터에서 경고가 뜬다.
3. mock_portfolio.md 이관 결과가 원본과 일치하고(이관 리포트 대사), 원본 파일은 변경되지 않는다(해시 동일).
4. 대시보드에 나라별 카드·순위 표·기준선 초과가 표시되고 값이 장부와 일치한다.
5. [[SCR-006]] AC 4건(배정금 표시·수기 검산·해당 없음·주차 전환)이 통과한다.
