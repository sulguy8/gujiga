## 상위 근거

**TSK-009 — 로컬 웹 서버·군영 현황판 화면**

**SCR-005 — 군영 현황판**
**DAT-011 — 관직·군령 위반 GeneralRank·Violation**
**REQ-013 — 관직·승진·군령 위반 초기화 관리**
**NTE-005 — 삼국지 게임 레이어: 병력·관직·성벽으로 규칙 준수 게임화**
**한 줄 요약: 매매 규칙을 삼국지 게임 용어(병사·관직·성벽·포로)로 입혀서, 규칙 지키기를 의무가 아니라 게임처럼 재미있게 만든다.**
규칙 기반 매매의 최대 적은 규칙 자체가 아니라 "규칙을 지키기 싫어지는 마음"이다. 이미 군주·출사표 같은 삼국지 세계관을 쓰고 있으므로, 이를 앱 전반의 게임 레이어로 확장해 규칙 준수 자체에 재미와 명예를 부여한다.

## 사전 환경 조건

- **검증 대상**: [[TSK-009]] 로컬 웹 서버와 군영 현황판([[SCR-005]]).
- 사전 조건: [[TST-004]] 통과, 테스트 장부(관직·포지션·포로 데이터) 준비.
- **실행 방법: 자동(HTTP 응답 검사) + 수동(군주 화면 검수)** — 모의 데이터 기준.

## 검증 시나리오 (Pass/Fail)

| # | 입력 | 기대 결과 | 방법 |
|---|---|---|---|
| 1 | 같은 PC에서 localhost 접속 | 현황판 표시 | 자동 |
| 2 | 다른 기기에서 PC IP로 접속 | 접속 불가(외부 바인딩 없음 — ARC-001 확정) | 수동(군주 휴대폰) |
| 3 | 관직·병력·성·포로·전공 표시값 | 장부(general_rank·position·captive_ledger) 값과 일치 | 자동 |
| 4 | 포로 발생일 데이터 주입 | "복수 출병 금지" 띠 표시 | 자동 |
| 5 | 현금 비중 34% 데이터 | 군량 게이지 주황 경고 | 자동 |
| 6 | 승진 조건 충족 데이터(출병 5·위반 0·복기 4주) | "승진 가능" 표시(자동 승진 아님) | 자동 |
| 7 | 화면에서 쓰기 요청 시도 | 거부(현황판은 읽기 전용) | 자동 |

## 경계값/에지 케이스

- 출병 0건: "전군 주둔 중" 빈 상태. 장부 파일 일부 없음: 해당 카드만 "집계 실패".
- 병사 수 환산 표시: 155,000원 포지션 → 15.5명이 아니라 명세대로(1만원=1명 환산 규칙) 표시 확인.
