## 사전 환경 조건

- **검증 대상**: [[TSK-021]] 병법서·논공행상 화면 보강 — 진행 막대·군주 판정·4분면·준수율.
- 사전 조건: [[TST-018]]·[[TST-019]] 통과, 테스트 데이터(4분면 각 1건 이상의 거래, 판정 대기 증거).
- **실행 방법: 자동(표시값 검사) + 수동(군주 화면 검수·판정 조작)**.

## 검증 시나리오 (Pass/Fail)

| # | 입력 | 기대 결과 | 방법 |
|---|---|---|---|
| 1 | 증거 7/10·출병 1/3 가설 상세 | 진행 막대 7/10 + 출병 1/3 정확 표시 | 자동 |
| 2 | 수익+준수 / 수익+위반 / 손실+준수 / 손실+위반 거래 각 1건 | 전공 / 요행(⚠) / 명예로운 패배 / 진짜 실패로 분류 표시 | 자동 |
| 3 | 논공행상 리포트 | 손익 열과 별도로 준수율·4분면 집계 표시, 수기 검산 일치 | 자동 |
| 4 | 판정 대기 증거를 화면에서 success 확정 | judged_by='군주' 기록 + 가설 집계 즉시 갱신 | 수동(군주) |
| 5 | 명예로운 패배와 진짜 실패의 표시 | 시각적으로 구분됨(색/배지) | 수동(군주) |
| 6 | 가설 상세의 등급별 병력 상한 안내 | 현 등급 기준 상한(예: 검증 중 → "현령 기준 10명") 표시 | 자동 |

## 경계값/에지 케이스

- 손익 0원 거래: 4분면 밖 '무승부'로 집계([[REQ-026]] 예외).
- 거래 0건 주간: 준수율 "해당 없음"(0으로 나누기 방지).
- 증거 10/10·출병 3/3 도달 시 진행 막대 완료 표시 + 승격 가능 안내.
