## 검증 시나리오 (Pass/Fail)

1. append-only: 의견 줄 수정·삭제 API가 없고, 채점은 score 이벤트 추가로만 (Pass: 원본 줄 불변).
2. 지수 대비 채점: 출병 + 종목 +3%·지수 +5% → miss / 반대 + 종목 −1%·지수 +1% → hit.
3. 관망 → excluded, 판정 건수 미포함.
4. 거래일 계산: 중간에 휴장 2일 → 달력일 7일 뒤 종가로 채점.
5. 지수 결측 → pending 유지, 10거래일 초과 → excluded(사유 기록).
6. 승진 경계: 10건 60% → 참군 / 9건 100% → 종사. 30건 65% → 군사중랑장.
7. 강등 경계: 최근 10건 적중 3건 → 강등, 4건 → 유지. 종사에서 더 안 내려감.
8. rank_at_time 소급 불변: 승진 후에도 과거 레코드 가중치 그대로.
9. 불일치율: 전원 일치 0%, 4:3 ≈ 43%, 폴백 제외 계산. 최근 10안건 평균 19% → 경고, 21% → 미경고.
10. 채점·재계산 배치 2회 실행 → 결과 동일(멱등), 중복 score 이벤트 없음.
11. 종가 출처 태그 검증: `source=krx_official`이 아닌 종가(예: 실시간 체결가·추정치)만 있는 경우 → 채점하지 않고 pending 유지 (Pass: hit/miss 미발생).
